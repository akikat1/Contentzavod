# assets/

| `generated/` | вдохи, импульс комнаты, SFX — создаются `factory init` процедурно | нет |

| `rvc/` | RVC-модель голоса канала (`channel_voice.pth`), только голос с правами | нет |
| `piper/` | офлайн-голоса Piper (`ru_RU-*.onnx`) | нет |
