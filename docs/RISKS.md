# Риски, лицензии и границы MVP

## Главные риски

| Риск | Митигация в коде |
|---|---|
| **YouTube Inauthentic Content** (июль 2026) — шаблонный контент не монетизируется | Format Rotation; QA-проверки «антишаблон» и «драматургия»; источники в описании; раскрытие ИИ (`containsSyntheticMedia`, текст в описании) |
| Бан аккаунтов провайдеров за мультиаккаунт | пул деградирует штатно: мёртвый ключ → алерт, работа на оставшихся; дно — llama.cpp |
| Free-тиры меняются без предупреждения | лимиты — данные в конфиге; `factory keys probe`; пул запоминает фактический суточный потолок (`learned_rpd`) |
| edge-tts блокирует при интенсивном использовании | синтез по предложениям с кэшем; фолбэк piper → espeak-ng; `factory doctor` |
| Галлюцинации фактов | источники только из найденных материалов (модель их не выдумывает); QA «факты»: число/цитата без источника → переписать; LLM-судья сверяет с фактами исследования |
| 4 ГБ VRAM — OOM | межпроцессный GPU-мьютекс, явная выгрузка, `small`/`int8`, чанки RVC |
| 16 ГБ ОЗУ — OOM | посценный рендер, ≤ 2 ffmpeg, аудио в numpy, `MemoryMax=13G` в systemd |
| Скрытый лимит загрузок канала YouTube | отказ → перенос на сутки, не ошибка |
| Refresh token YouTube отзывается через 7 дней | в SETUP: перевести OAuth-приложение в «In production» |
| Ремонт по кругу | детектор «ремонт не изменил результат QA» → сразу карантин и алерт; максимум 3 цикла |
| Переполнение диска | уборка промежуточных файлов, лимит истории, стоп производства при < 40 ГБ |

## Лицензионные решения

| Компонент | Решение | Причина |
|---|---|---|
| Оркестратор | свой (Python + SQLite + systemd) | n8n: Sustainable Use License ограничивает коммерческое использование; GUI-воркфлоу не ревьюится в git |
| Программное видео | FFmpeg + PIL | Remotion бесплатен только до 3 сотрудников |
| Генерация видео | не используется | на 4 ГБ невозможна; при апгрейде — Wan 2.2 (Apache 2.0), а не LTX (бесплатен до $10M выручки) |
| Ассеты звука | процедурные (генерируются кодом) | в репозитории нет чужих файлов с неясной лицензией |
| Сток | Pexels, Pixabay | бесплатно, коммерческое использование, атрибуция не обязательна |
| Postiz | отдельный контейнер | AGPL-3.0 — не встраиваем код, общаемся по API |
| RVC | внешний CLI | тяжёлые зависимости вне пакета; модель — только на голосе с правами |

## Отличия реализации от плана

- **Стадий 16 + сбор статистики.** Feedback (s17) запускается демоном раз в 6 часов по всем опубликованным
  роликам, а не внутри джоба: удержанию нужно 48 часов.
- **Выравнивание.** WhisperX не обязателен: edge-tts отдаёт настоящие пословные тайминги. faster-whisper
  подключается только для офлайн-движков (piper, espeak) или по `align.engine: whisper`.
- **Инвариант смены голоса уточнён**: внутри блока может звучать не только цитата, но и реплика персонажа —
  в диалоге каждая реплика сама является смысловой единицей. Смена *нарратора* — только на границах блоков.
- **Громкость**: вместо loudnorm — лимитер + линейный подъём (loudnorm недобирал 2 LU на голосе с пиками).
- **Драматургия в QA** проверяется по реальной озвучке с допуском 15 % — синтез всегда отклоняется от плана.

## Что не входит в MVP

| Не сделано | Почему / как добавить |
|---|---|
| Дзен | публичного API нет; нужен Playwright по живому UI — хрупко, отдельная задача |
| MusicGen | на 4 ГБ конкурирует за GPU с остальными стадиями; вместо него — библиотека треков + процедурная подложка |
| CTR в статистике | YouTube Analytics API не отдаёт CTR обложки стабильно; стиль заголовка пока выбирается ε-жадно с исследованием |
| Проверка живыми ключами и площадками | среда разработки блокирует внешние API; реальные вызовы проверяются на вашей машине: `factory keys probe`, `factory run --dry-run`, затем YouTube `private` |
| NSFW-классификатор | необязательный (`pip install nudenet`); ассеты — из модерируемого стока и генерации с фильтрами. Сделать обязательным: `qa.nsfw.required: true` |
